## 🚀 Deployment Guide

### Option 1: GitHub Pages (Recommended)
1. Create a new repository on GitHub named `lofi-bot-website`.
2. Upload all files from the `website/` folder to the repository.
3. Navigate to **Settings > Pages**.
4. Set the source to the `main` branch and the folder to `/ (root)`.
5. Your site will be live at `https://YOUR_USERNAME.github.io/lofi-bot-website/`.

### Option 2: Netlify (Fastest)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `website/` folder onto the page.
3. Your site will be deployed instantly!
